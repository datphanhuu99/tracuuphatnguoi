## Mybot — liên kết bộ nhớ trung tâm

Đọc `../AGENTS.md` và `../mybot/AGENTS.md` trước khi làm việc. Các đường dẫn trong hướng dẫn workspace tính từ thư mục cha của project này.
Project hiện tại là `tracuuphatnguoi`; chỉ nạp shared và memory của project này.
Nếu hook chưa cung cấp danh mục Memory Mybot, chạy một lần đầu phiên từ gốc project: `rtk proxy python3 ../mybot/session-start.py --client codex --project tracuuphatnguoi`. Khi gọi lệnh ghi/tìm memory từ gốc workspace, truyền `--project tracuuphatnguoi`.
Hướng dẫn sửa code riêng của project vẫn được ưu tiên.
